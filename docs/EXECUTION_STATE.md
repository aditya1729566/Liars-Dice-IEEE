# Execution state — 8 November 2026

The repository has an isolated `main` branch and an active `codex/bluff-exe` implementation branch. The C++ fixed-five ruleset, loopback persistence API, three heuristics, two sampled-CFR versions, public-outcome adaptive candidate, Next.js 2D interface, production kiosk, and Vercel deployment are implemented. The old one-die/dice-elimination policy remains retired.

The public Vercel address is `liarsdice5.vercel.app` (the project retains the name `liars-dice-ieee`). Its Next.js function runs a Linux-built copy of the same C++ engine and persists match state in a private Blob store with conditional ETag writes. A first deployed match exposed a weak content ETag conflict; switching to Blob metadata ETags fixed it. On the corrected preview, a six-round game completed 11 human actions, six reveals, 35 replay slides, and six recorded AI decisions; a duplicate action returned an identical response. That test match was deleted afterward. The production browser then started a match, showed five concealed AI dice while bidding, and revealed both hands after a challenge. `make verify` passed before deployment with 10 engine, 4 trainer, and 4 API tests plus lint, typecheck, and build. These are deployment checks, not training or human-performance results.

On 8 November, the interface was redrawn as a sharp 2D scorecard with CSS dice, responsive controls, and a post-match Research journal. A completed match exposes recorded AI decisions, its own hand, binomial truth priors, sampled action weights, and reveal outcomes; active matches keep its private hand redacted. The wider `fixed5_cfr_v2_100k` candidate trained for 100,000 iterations on the same fixed-five rules with more raise choices and preceding-bid context. The follow-up paired-seed confirmation is recorded in `fixed5_cfr_v2_confirm_400`; the new policy's status is determined from its registered gates in the evidence report.

The Research journal now has a complete slide-by-slide replay of every authoritative match event plus each challenge, with post-match hands, scores, claims, actual counts, AI priors, and sampled policy options. The AI's readings of human moves are explicitly labeled reconstructions from its own hand and public actions. Unit and HTTP tests check event coverage, completed-only access, and invariance of the interpretation to a hidden human-hand change. That production-browser desktop and mobile replay inspection passed, including keyboard navigation, round jump, final slide, and a 390-pixel viewport without horizontal overflow. An audit generated 1,569 ordered slides across 38 stored completed matches. `make verify` passed with 10 engine, 4 trainer, and 4 API tests plus lint, TypeScript, and the production build.

`fixed5_cfr_100k` completed 100,000 bounded one-round abstraction iterations and saved a resumable checkpoint plus SHA-256-identified policy. `fixed5_five_agent_holdout_200` completed 4,000 seat-balanced matches with 74,709 logged decisions and zero run errors. `fixed5_hard_holdout_200` completed 6,000 matches with 136,422 decisions and zero run errors. The 12,000-match paired-seed original-CFR confirmation completed with 292,730 decisions, zero run errors, and a +7.15 percentage-point league advantage over probability (95% paired bootstrap [5.73, 8.55]); it was the first measured local champion. Both fresh same-seed control runs completed without run errors; paired static and switching comparisons are in the final report.

The 2,400-match `fixed5_cfr_v2_confirm_400` run completed with 69,298 logged decisions and zero run errors. V2 won 523/800 direct games against the original CFR (65.4%, Wilson 95% [62.0, 68.6]); it won 594/800 against probability (74.3%, [71.1, 77.2]). Its fresh-process decision p95 was 40.25 ms. It passed the registered promotion checks and is the active selectable Apprentice. The original CFR won 613/800 against probability on those same seeds, so this promotion is a robustness choice with a measured probability-opponent tradeoff, not a claim that v2 dominates every opponent.

`make verify` passed after the five-agent integration.
